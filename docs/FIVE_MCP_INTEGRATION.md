# BIORICHEBRAIN — подключение пяти MCP-серверов

Этот набор добавляет пять MCP-серверов к уже существующему Exa MCP в `.vscode/mcp.json`.

## Что подключено

| Сервер | Назначение | Подключение / авторизация |
|---|---|---|
| Perplexity | Поиск и исследование с ответами на основе веб-источников | Hosted MCP; требуется собственный Perplexity API key |
| Playwright | Управление отдельным браузером для тестов и автоматизации | Локальный stdio через `npx`; Node.js 20+ |
| Firecrawl | Поиск, извлечение и парсинг веб-страниц | Hosted MCP; базовый доступ может работать без ключа в ограниченном бесплатном режиме; расширенные функции требуют ключ |
| Glif | Доступ к workflow генерации контента | Hosted MCP с OAuth; генерация расходует кредиты аккаунта |
| Chrome | Управление текущим профилем Chrome и вкладками | Локальное расширение + bridge; HTTP только на loopback |

## Перед запуском

1. Откройте репозиторий в VS Code и обновите ветку.
2. Установите Node.js 20 или новее.
3. Перезапустите VS Code после изменения MCP-конфигурации.
4. Не добавляйте API-ключи, токены, cookies или файлы профиля браузера в Git.

## Perplexity: безопасная настройка ключа

MCP-конфигурация читает ключ из переменной окружения `PERPLEXITY_API_KEY`. Не вписывайте сам ключ в JSON.

Linux/macOS (запустить VS Code из того же терминала):
```bash
export PERPLEXITY_API_KEY="ВАШ_ЛИЧНЫЙ_API_KEY"
code .
```

PowerShell:
```powershell
$env:PERPLEXITY_API_KEY = "ВАШ_ЛИЧНЫЙ_API_KEY"
code .
```

Ключи из чужих репозиториев, публичных gist, случайных сайтов и коммитов не использовать: они могут быть украдены, отозваны или принадлежать другому человеку. Если ключ уже попадал в публичный Git, немедленно отзовите его и выпустите новый.

## Playwright

Сервер запускается VS Code через `npx -y @playwright/mcp@latest`. При первом запуске npm скачает пакет. Режим `--headless` не открывает видимое окно браузера; для визуальной отладки удалите этот аргумент в локальной конфигурации. Playwright использует отдельный браузерный контекст и не должен считаться подключением к личному профилю Chrome.

## Firecrawl

В конфигурации используется hosted endpoint `https://mcp.firecrawl.dev/v2/mcp`. Доступность бесплатных базовых инструментов и лимиты определяются Firecrawl и могут меняться. Для платных/расширенных возможностей настройте личную авторизацию по актуальной документации Firecrawl; секреты не коммитить.

## Glif

Используется официальный hosted endpoint `https://glif.app/api/mcp`. При первом подключении пройдите OAuth в клиенте, если он предложит авторизацию. Само подключение не означает бесплатную генерацию: изображения, видео и другие workflow могут расходовать кредиты Glif.

## Chrome MCP: локальная установка

1. Скачайте актуальный релиз расширения: https://github.com/hangwin/mcp-chrome/releases
2. В Chrome откройте `chrome://extensions/`, включите Developer mode и загрузите распакованную папку расширения через Load unpacked.
3. Установите bridge:
   ```bash
   npm install -g mcp-chrome-bridge
   ```
4. Откройте расширение, нажмите Connect и проверьте, что локальный сервер запущен.
5. Ожидаемый Streamable HTTP endpoint проекта: `http://127.0.0.1:12306/mcp`.

Chrome MCP работает с существующим профилем браузера и его авторизованными сессиями. Используйте отдельный профиль Chrome для автоматизации, не поручайте агенту финансовые/административные действия без подтверждения и не запускайте bridge на публичном сетевом интерфейсе.

## Проверка после установки

В VS Code откройте панель MCP (команда **MCP: List Servers** / список MCP-серверов в зависимости от версии VS Code) и проверьте статусы:

- `perplexity` — доступен после настройки переменной окружения и действующего API key;
- `playwright` — доступен после загрузки пакета; при первом запуске может потребоваться установка браузера;
- `firecrawl` — доступен при работающем hosted endpoint и допустимом лимите;
- `glif` — доступен после OAuth;
- `chrome` — доступен только когда расширение и bridge запущены локально.

Затем откройте журнал соответствующего MCP-сервера и выполните безопасный тест чтения/поиска. Не тестируйте отправку форм, публикацию, покупку или удаление данных.

## Важные ограничения

- Коммит конфигурации не устанавливает расширение Chrome на ваш компьютер и не авторизует Perplexity/Glif.
- Удалённые hosted MCP endpoints зависят от условий и доступности провайдера.
- Не считать MCP-сервер доверенным только потому, что он опубликован на GitHub. Перед обновлением проверяйте владельца репозитория, релиз, лицензию и изменения.
- Конфигурация предназначена для локальной разработки. Не включайте эти MCP-инструменты в автономный агентный цикл без allowlist, sandbox, журналирования и подтверждения рискованных действий.
