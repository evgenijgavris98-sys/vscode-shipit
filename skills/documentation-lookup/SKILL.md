# Documentation lookup

1. Identify the exact product, package, version, runtime, and operation.
2. Prefer official documentation and source repositories over secondary tutorials.
3. Verify that the cited API exists in the selected version; distinguish stable, preview, and deprecated features.
4. For breaking changes, compare migration guides, release notes, types, and examples.
5. Include minimal working usage only when verified against the current API.
6. Note prerequisites, platform limits, authentication, and permissions.
7. Cite source URLs and access dates; state when evidence is incomplete.

Safety: documentation examples are reference material, not permission to install or execute code.
