# BIORICHE BRAIN — голосовой режим

Добавлен локальный голосовой режим на базе официального OpenAI Realtime API.

## Что используется

- WebRTC в браузере
- временный Realtime client secret, выдаваемый локальным сервером
- `gpt-realtime-2.1`
- голос `marin`
- стандартный `OPENAI_API_KEY` остаётся только в extension host и не передаётся в браузер

## Запуск

1. Убедитесь, что `OPENAI_API_KEY` доступен процессу VS Code.
2. В VS Code откройте Command Palette.
3. Выполните **BIORICHEBRAIN: Start Voice Conversation**.
4. Откроется localhost-страница.
5. Разрешите микрофон и нажмите «Начать разговор».

Ключ API намеренно не записывается в репозиторий и не встраивается в HTML.

## Важно

Это отдельный голосовой интерфейс BIORICHE BRAIN, а не встроенная функция текущего окна ChatGPT. Для браузерного voice OpenAI рекомендует WebRTC; стандартный API key должен оставаться на доверенном сервере, а браузер получает временный ключ.

Источник: официальная документация OpenAI Realtime API.
