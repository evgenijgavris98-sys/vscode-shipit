# Agent Registry and Governance

Maintain the actual code-backed agent registry and, for each agent, role, owner, inputs/outputs, allowed tools, denied actions, memory scope, budget ceiling, evaluation, escalation path and dependencies.

Count agents from the registry and tests, not from planned roles or markdown files. Default-deny permissions; human approval is required for publishing, purchases, deployment, destructive edits and external commitments. Skills provide guidance only and never grant permissions.
